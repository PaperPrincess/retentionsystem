# Проактивная система удержания студентов (Student Retention System)

Данный репозиторий содержит исходный код дипломного проекта по разработке методологии проактивного удержания пользователей в образовательных средах. Система базируется на гибридных моделях прогнозирования латентного оттока и адаптивном рекомендательном анализе (RAG + LLM).

## 📌 Описание проекта

Традиционные методы удержания студентов в LMS (Learning Management System) работают реактивно — когда студент уже провалил экзамен или перестал заходить на платформу. Наша система работает на опережение: она анализирует цифровой след студента в реальном времени и, в случае выявления паттернов оттока, автоматически формирует персонализированные интервенции с помощью искусственного интеллекта.

## 🛠 Технологический стек

* **Backend:** Python 3.10+, FastAPI
* **Аналитическая БД (Сбор логов):** ClickHouse
* **Транзакционная БД (Профили и результаты):** PostgreSQL (pgvector для RAG)
* **Асинхронные задачи:** Celery + Redis
* **Machine Learning:** CatBoost (табличные данные), PyTorch + LSTM (временные ряды)
* **AI / NLP:** Интеграция с LLM API (YandexGPT / GigaChat) через RAG-архитектуру
* **Инфраструктура и CI/CD:** Docker, GitHub Actions / GitVerse Pipelines
